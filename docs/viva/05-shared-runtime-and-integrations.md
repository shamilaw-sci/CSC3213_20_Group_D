## Important deployment consequences

Production PostgreSQL now verifies certificates instead of accepting arbitrary chains. Configure the trusted CA in DB_SSL_CA when system trust is insufficient; do not disable validation. URL-level SSL overrides are intentionally ignored in production. The previously observed Supabase certificate-chain failure remains unresolved environment work, with no reconnect attempted here. Development SSL behavior is unchanged and must not be described as secure remote transport.

Audit is best-effort and route-specific. A denied request logged after finish is not a completed clinical operation; the recorded status/outcome distinguishes it. Direct service/controller logAudit events may still represent business milestones separately. Required durability/fail-closed audit policy, retention/access controls and coverage of rejected-before-middleware/aborted requests remain open.

Optional AI/Storage configuration must not make unrelated roles/routes unavailable. A missing integration causes explicit feature failure/fallback, not fabricated success. This does not make AI or photo workflows verified end to end.

## Viva changes / questions

- **Add a provider key:** change deployment configuration, not source literals. Update `.env.example` names only. Never put credentials in docs/tests.
- **Change DB trust:** Ctrl+F `DB_SSL_CA` / `rejectUnauthorized`; keep URL override removal and test effective installed pg SSL options.
- **Add audit fields:** Ctrl+F `auditMiddleware` for HTTP metadata, `logAudit` for explicit events; avoid raw payloads/capabilities and preserve redaction.
- **Change email copy:** edit the corresponding send* template; retain escapeHtml and distinguish submission from delivery.
- **Change retries/models:** Ctrl+F GEMINI_MAX_ATTEMPTS / GEMINI_RETRY_DELAYS / model constants; verify supported provider contract separately, without clinical traffic.
- **Why release the probe client?** pool.connect borrows a slot until release; a successful log alone does not return it.
- **Why record route patterns?** Raw QR/NIC URLs can disclose capabilities/identifiers and do not fit the audit UUID entity column.
- **Why not mark audit complete globally?** Only instrumented requests reaching middleware and finishing are captured; storage remains best-effort.
