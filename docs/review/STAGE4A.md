## Open findings and limits

- Clinical category classification is still phrase matching and can miss sensitive diagnoses. User reported no agreed mapping and requested a simple practical approach; retained existing labels and matcher with explicit limitations, rather than inventing a clinical diagnosis taxonomy or silently hiding all records. `is_confidential` is presentation metadata, not an independent backend consent policy. Agree an explicit category model in a later clinical/schema decision.
- Grant revocation exists when successful verification supersedes a previous grant. A patient-operated revoke endpoint, lock-change revocation, pending-code cancellation and real-time revocation display are not implemented; existing behavior is preserved, not advertised as instant revocation.
- Consent code generation still lacks a rolling request budget; the five-failure cap is per request. Global/persistent limits and repeated-resend protection need a focused safeguard follow-up; this is not declared fixed. C3-11 public pharmacy/lab registration limits/enrollment/atomicity remains OPEN.
- Profile-link cardinality, medical safety/chronic-condition confidentiality, AI provider/privacy policy, photo bucket/public URL policy, CSRF, Supabase grants/Data API exposure and inherited unrelated-module findings remain pending.
- Mocked SQL does not prove real transactions, locks, isolation, rollback, wall-clock behavior or races; browser fixtures do not prove cookies, DB, providers or root-app navigation. Native/back/font scaling/assistive tech and other browsers are not verified.
